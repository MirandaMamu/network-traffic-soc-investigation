# Network Traffic & SOC Investigation Lab

## Project Overview

This project demonstrates beginner-level Security Operations Center (SOC) investigation skills combined with practical networking fundamentals.

The investigation focuses on analysing network activity, identifying suspicious behaviour, reviewing indicators of compromise (IOCs), and documenting an appropriate incident response.

## Skills Demonstrated

- Network fundamentals
- TCP/IP
- IP addresses
- TCP and UDP
- Ports and protocols
- DNS analysis
- HTTP traffic
- Network traffic analysis
- SOC alert triage
- Log analysis
- Incident investigation
- Indicators of compromise (IOCs)
- Incident response documentation
